# DripsTech — One Brand. One System. Zero Inconsistency.
## Complete Frontend Unification Guide

> **The problem in one sentence:** Every section of this site was written by a different AI session with zero awareness of each other — 3 hero variants, 6+ different green shades, `gray-*` vs `slate-*` vs `muted` used randomly, hardcoded hex colors sitting next to CSS variables. This guide kills all of that with one unified system.

---

## PART 1: THE ROOT CAUSE AUDIT

Here is exactly what was found in the codebase. Every item below is a real inconsistency that needs to die.

### 1.1 Dead Components (Delete These Files)
These components exist in the repo but are **not being used**. They are design waste from previous AI sessions:

```
DELETE: src/components/Home/HeroSection.tsx       ← uses emerald-600, slate-900 hardcodes
DELETE: src/components/Home/HeroSectionModern.tsx ← uses emerald-500, Unsplash images, parallax gimmick
KEEP:   src/components/Home/HeroSectionVibe.tsx   ← this is the active one (used in Home.tsx)
```

Keeping dead components around means future AI sessions will accidentally reuse their color patterns. Delete them.

### 1.3 The Font Problem

In `src/index.css`, the design system declares:
```css
--font-heading: "Inter", sans-serif;
--font-body: "Inter", sans-serif;
```

**Inter for everything = instant AI tell.** There is no font differentiation between headings and body copy anywhere.

### 1.4 The Border Radius Problem

`tailwind.config.ts` sets `--radius: 0.75rem` and every shadcn component inherits it. The result: **everything is rounded-xl**. Cards, buttons, badges, inputs, dropdowns — all identically soft. This is the single biggest visual cue that screams "AI default."

### 1.5 The Footer Problem

```tsx
// Current footer — invisible, blends with page
<footer className="bg-background border-t border-border">
```

White footer on a white page. Zero visual grounding. No brand anchor at the bottom.

### 2.2 `index.html` — Font Loading

Replace any existing Google Fonts link with:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Syne:wght@700;800;900&family=Plus+Jakarta+Sans:wght@300;400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
```

**Why these fonts:**
- **Syne** — geometric, bold, African-editorial energy. Used by agencies and premium brands. Completely unexpected for irrigation.
- **Plus Jakarta Sans** — clean and modern but not Inter. Has personality, great at small sizes, excellent Swahili character support.
- **JetBrains Mono** — exclusively for prices and specs. Makes "KSh 12,500" look precise and trustworthy.

### 3.1 `src/components/common/SectionHeader.tsx` — REWRITE

This is used on every page. Fix it once, fix everything.

```tsx
import React from "react";

interface SectionHeaderProps {
  label?: string;        // Small ALL-CAPS label above title e.g. "Our Products"
  title: string;
  subtitle?: string;
  align?: "left" | "center";
  className?: string;
}

const SectionHeader: React.FC<SectionHeaderProps> = ({
  label,
  title,
  subtitle,
  align = "center",
  className = "",
}) => {
  const alignClass = align === "left" ? "text-left items-start" : "text-center items-center";

  return (
    <div className={`flex flex-col gap-3 mb-10 sm:mb-14 ${alignClass} ${className}`}>
      {label && (
        <span className="dt-section-label">{label}</span>
      )}
      <h2 className="dt-section-title">{title}</h2>
      {subtitle && (
        <p className={`dt-section-subtitle ${align === "center" ? "mx-auto" : ""}`}>
          {subtitle}
        </p>
      )}
    </div>
  );
};

export default SectionHeader;
```

- `bg-destructive` / `text-destructive` — error states, that's correct
